| Stage                    | What it contains (one line)                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| 1. Planning              | Identify the problem, objectives, project scope, feasibility, risks, budget, and timeline.         |
| 2. Requirements Analysis | Gather and document functional and non-functional requirements (what the software must do).        |
| 3. System Design         | Design the architecture, database, APIs, UI/UX, and technology stack (how the software will work). |
| 4. Implementation        | Write code, build components, integrate modules, and manage code using version control.            |
| 5. Testing               | Find defects and verify correctness through unit, integration, system, and acceptance testing.     |
| 6. Deployment            | Release the application to a server or production environment and configure it for users.          |
| 7. Maintenance           | Fix bugs, monitor performance, apply updates, improve features, and handle changing requirements.  |
