### Interview Overview

### React Questions

- **React vs. Plain JavaScript:** Jairam described React as declarative with reusable components that can embed HTML, while plain JavaScript is limited to DOM manipulation and cannot inject HTML directly into functions — the interviewer noted key points were covered but moved on without pressing for more depth
- **Functional vs. Class Components:** Jairam explained functional components use JavaScript functions without a `render` keyword, while class components use `render` and support inheritance — when asked about state and lifecycle differences, Jairam acknowledged limited in-depth knowledge of those areas
- **What is a Component:** Described as a reusable block of code that renders HTML and promotes modularity; components can be organized in separate folders, imported, and used as tags in a central file — the interviewer acknowledged the response covered reusability and modularity well

### REST API Questions

- **Request Parameters vs. Request Body:** Jairam explained parameters are sent via the URL for smaller/specific operations or resource fetching, while the request body carries a larger JSON payload for backend processing
- **What is a REST API:** Described as Representational State Transfer — an interface enabling communication between web applications and backend servers over HTTP
- **Authentication vs. Authorization:** Jairam clearly distinguished the two: authentication is identity verification (proving who you are), while authorization checks whether an already-authenticated user has permission to access a specific resource
